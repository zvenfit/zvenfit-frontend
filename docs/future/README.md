# Future roadmaps

Здесь хранятся проработанные идеи, которые ещё не согласованы для реализации.
Они не являются активным backlog, обещанием сроков или описанием текущей
production-архитектуры.

- [`fitbase-integration-plan.md`](fitbase-integration-plan.md) — технический
  discovery-план будущего развития интеграции с FitBase.
- [`fitbase-integration-manager-plan.md`](fitbase-integration-manager-plan.md) —
  версия предложения для согласования с менеджером.
- [`astro-migration-plan.md`](astro-migration-plan.md) — discovery-план
  миграции фронтенда на Astro: инварианты, этапы и PR, проверка паритета,
  решения владельца.
- [`ideas.md`](ideas.md) — короткие идеи без проработки: MAX как второй канал
  уведомлений, проверка обработки персональных данных.
